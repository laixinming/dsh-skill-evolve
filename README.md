# dsh-skill-evolve — Skill 全域自演化架构

> 在 DeepSeek Harness (DSH) 上实现"全局/工作区双层 Skill 生态 + 自动进化 + 升降级 + 自动生成"的闭环 Agent 工程系统。
> **常驻宿主插件**：DSH 启动即加载，所有会话共享，数据持久化，随使用持续演化。

---

## 一、这是什么

LLM（内脑）提供先天推理本能，Harness（外脑）提供**后天可进化能力**。本系统让 Agent 使用的技能（Skill）像生物一样：

- **积累经验** —— 每次调用被记录（成功/失败、频率、成本）
- **优胜劣汰** —— 高频好用的工作区技能**自动升级为全局**；长期闲置的全局技能**自动降级回工作区**
- **补全能力** —— 某类诉求连续缺失时**自动生成新 Skill 草稿**，经你审核后启用
- **持续优化** —— 技能内容可被自动迭代，且**脏检测**防止覆盖你的手动修改

## 二、功能总览

| 子系统 | 能力 |
|---|---|
| **双层 Skill 生态** | `global-skills/`（全局）与 `workspace/.dsh/workspace-skills/`（工作区）；解析顺序 引导 → 全局 → 工作区；`scope+name` 联合键避免命名冲突 |
| **计量中心** | 30 天滑动窗口统计：调用占比、成功率、趋势；`auto_generated` 技能频率权重衰减 ×0.5；每日聚合；候选池 GC（7 天过期 + Levenshtein 去重） |
| **升降级网关** | 升级需 30 天占比 ≥0.1% 且成功率 ≥92% 且无耦合、非锁定、非黑名单；降级需**连续双窗口** ≤0.01% + 反向依赖检测；**30 天冷却期防震荡**；降级用**三方合并**（冲突→告警暂停）；全程账本快照可回滚 |
| **自动生成** | 缺失检测（哈希 + Jaccard 语义聚类，连续 3 次触发）→ 生成草稿 → **待审核队列**（7 天过期）；**负反馈黑名单**（同一诉求拒收 3 次永久屏蔽） |
| **通知服务** | 6 种类型卡片（升级🔼/降级🔽/生成🧠/告警⚠️/信息ℹ️/成功✅），24h 去重、忽略后 7 天静默、**一键回滚/锁定/审核/恢复**按钮 |
| **可观测 UI** | ① 聊天界面右下角**常驻通知卡片栏**（所有会话生效）；② 完整**网页仪表盘** `http://127.0.0.1:3080/skill-evolve`（统计卡/热度排行/濒临预警/演化时间线/待审核/配置/演示按钮） |

## 三、日常工作中它怎么生效

1. **每次使用都是数据**：你（或 Agent）执行技能时自动记录调用。日积月累，系统知道哪些技能"好用"。
2. **自动升级**：某个工作区技能 30 天内被高频稳定使用（占比 ≥0.1%、成功率 ≥92%）→ 系统自动把它升级为**全局技能**（所有项目可用），原工作区保留代理转发。聊天里弹出绿色卡片，可一键回滚。
3. **自动降级**：某个全局技能 30 天没人用（连续两窗口占比 ≤0.01%）→ 自动降级回它来源的工作区，全局库瘦身。橙色卡片可一键恢复。
4. **自动生成**：连续 3 次同类诉求系统都找不到对应技能 → 自动生成草稿并弹蓝色卡片，你点"✅ 审核通过"即启用；点"❌ 拒绝并拒收"则同类诉求 3 次后永久不再打扰。
5. **防误伤**：你的手动修改会被脏检测保护；锁定/冷却期/黑名单/观察者模式（只观察不应用）给你完全控制权。
6. **重启不丢**：数据全部落盘 `D:/DSH/.skill-evolve/`，宿主插件随 DSH 启动自动加载，所有会话共享同一套演化状态。

## 四、给 Agent 的入口（所有会话可用）

- `evolve_status` 查看系统状态（计数/热度/时间线/待审核/配置）
- `evolve_selftest` 一键运行 23 项典型场景自验证
- `evolve_resolve` 按 引导→全局→工作区 解析一个诉求命中哪个 Skill
- `evolve_run` 执行（模拟）一个 Skill 并记录计量
- `evolve_demo` 触发典型演化场景（promote/demote/generate/split/lock/rollback）用于演示

